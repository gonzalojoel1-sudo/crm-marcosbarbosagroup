# Plan de implementación — Nivel 1: Página "Hoy"

> **Para quien implementa:** seguir las tasks en orden. Cada task termina con un
> paso verificable (test o chequeo concreto), no con "quedó listo".

**Goal:** una página `/hoy` en producción que muestra pendientes del día y
permite alta rápida, en menos de 1 segundo.

**Spec:** `docs/superpowers/specs/2026-09-15-nivel1-hoy-design.md`

**Stack:** Frappe v15 (`www` page + api.py), Python, JS mínimo. Sin build, sin
frameworks.

## Restricciones globales

- Zona horaria: **America/Argentina/Cordoba** (verificada en el sitio).
- DocType de tareas: `Task` (custom, limpio).
- DocType de eventos: `Event` (el de Frappe: `subject`, `starts_on`, `ends_on`).
- "Hoy" = `[hoy 00:00, mañana 00:00)` en tz del sitio.
- Todos los métodos de API: `@frappe.whitelist()` (requieren login).
- **Vista de equipo:** la página muestra TODAS las tareas abiertas (somos 1-3
  personas). El filtro por usuario queda para Nivel 2.
- Ningún cambio a la app `/crm` existente.
- Sin nuevas dependencias.

```python
# apps/crm_core/crm_core/api.py
import frappe
from frappe.utils import getdate, add_days, nowdate

def _day_bounds(day=None):
    day = getdate(day or nowdate())
    return f"{day} 00:00:00", f"{add_days(day, 1)} 00:00:00"

@frappe.whitelist()
def get_hoy():
    start, end = _day_bounds()
    task_fields = ["name", "subject", "due_datetime", "priority"]

    overdue = frappe.get_all(
        "Task",
        filters={"status": "Open", "due_datetime": ["<", start]},
        fields=task_fields, order_by="due_datetime asc", limit_page_length=0,
    )
    tasks_today = frappe.get_all(
        "Task",
        filters={"status": "Open", "due_datetime": ["between", [start, end]]},
        fields=task_fields, order_by="due_datetime asc", limit_page_length=0,
    )
    events_today = frappe.get_all(
        "Event",
        filters={"starts_on": ["between", [start, end]], "status": ["!=", "Cancelled"]},
        fields=["name", "subject", "starts_on", "ends_on"],
        order_by="starts_on asc", limit_page_length=0,
    )
    return {
        "today": str(getdate()),
        "overdue": overdue,
        "tasks_today": tasks_today,
        "events_today": events_today,
        "count": len(overdue) + len(tasks_today),
    }
```

- [ ] **Step 1: `hoy.py` arma el contexto**

```python
import frappe
from crm_core.api import get_hoy

no_cache = 1

def get_context(context):
    if frappe.session.user == "Guest":
        frappe.local.flags.redirect_location = "/login"
```

```html
  <title>Hoy</title>
```

- [ ] **Step 2: Implementar**

```python
@frappe.whitelist()
def quick_add_task(subject):
    subject = (subject or "").strip()
    if not subject:
        frappe.throw("La tarea no puede estar vacía")
    doc = frappe.get_doc({
        "doctype": "Task", "subject": subject,
        "status": "Open", "owner": frappe.session.user,
    })
    doc.insert()
    return {"name": doc.name, "subject": doc.subject}
```

- [ ] **Step 3: JS de alta rápida**

```javascript
// apps/crm_core/crm_core/public/js/hoy.js
const csrf = (window.frappe && frappe.csrf_token) || "";
async function call(method, args) {
  const r = await fetch(`/api/method/crm_core.api.${method}`, {
    method: "POST",
    headers: { "Content-Type": "application/json", "X-Frappe-CSRF-Token": csrf },
    body: JSON.stringify(args || {}),
  });
  if (!r.ok) throw new Error(await r.text());
  return (await r.json()).message;
}
const input = document.getElementById("quick");
input.addEventListener("keydown", async (e) => {
  if (e.key !== "Enter") return;
  const v = input.value.trim();
  if (!v) return;
  input.value = "";
  try { await call("quick_add_task", { subject: v }); location.reload(); }
  catch (err) { input.value = v; alert("No se pudo crear la tarea"); }
});
```

- [ ] **Step 2: Implementar**

```python
@frappe.whitelist()
def complete_task(name):
    if not frappe.has_permission("Task", "write", doc=name):
        frappe.throw("Sin permiso para modificar esta tarea", frappe.PermissionError)
    frappe.db.set_value("Task", name, "status", "Done")
    return {"ok": True}
```

- [ ] **Step 3: JS con actualización optimista**

```javascript
// agregar a hoy.js
document.querySelectorAll('input[type=checkbox][data-name]').forEach((cb) => {
  cb.addEventListener("change", async () => {

    label.classList.add("done");           // optimista
    try { await call("complete_task", { name: cb.dataset.name }); }
    catch { label.classList.remove("done"); cb.checked = false; alert("No se pudo completar"); }
  });
});
```
